# BÁO CÁO PHÂN TÍCH KIẾN TRÚC & MÃ NGUỒN - CAPCUT INJECTOR PRO

**Dự án:** CapcutInjector Pro (V2 Automation Suite)
**Tác giả:** XunNghiax / Yi
**Mô hình thiết kế:** MVC (Model-View-Controller) & OOP

---

## 1. TỔNG QUAN KIẾN TRÚC HỆ THỐNG
Dự án được thiết kế để tự động hóa hoàn toàn quy trình: Tải Video -> Nhận diện giọng nói -> Dịch thuật AI -> Sửa lỗi QA -> Sinh giọng nói TTS -> Nhúng vào CapCut.
Hệ thống áp dụng chuẩn MVC phân tách triệt để:
- **Tầng View (Giao diện):** `gui_v2.py` (PyQt6). Không chứa logic xử lý nặng, chỉ vẽ UI và nhận cấu hình.
- **Tầng Controller (Điều phối):** `src/workers.py` chạy đa luồng (Multi-threading). Đảm bảo UI không bị treo (Not Responding) và có khả năng Pause/Resume an toàn.
- **Tầng Model (Logic Lõi):** Thư mục `src/` chứa các module chuyên biệt (`gemini_bot.py`, `backend.py`, `srt_manager.py`, v.v.).

## 2. PHÂN TÍCH CHI TIẾT CÁC MODULE CỐT LÕI

### 2.1. Module Điều Phối Trung Tâm (`src/workers.py`)
Class `ProcessWorker` kế thừa `QThread` quản lý vòng đời của dự án qua 6 bước:
1. **Bilibili Downloader:** Tải nguồn video/audio.
2. **Subtitle Generator:** Dùng Whisper bóc băng. Tích hợp làm chậm (0.8x) mốc thời gian để phù hợp với ngữ âm Tiếng Việt, sau đó cắt nhỏ file SRT gốc ra nhiều parts (mặc định 100 dòng/part).
3. **AI Translation:** Dịch file nhỏ bằng vòng lặp. Có cơ chế quét lại (`MAX_GLOBAL_RETRIES = 3`) chống sót file.
4. **Auto QA (Iterative Healing):** Tự động phát hiện lỗi dịch đè thời gian, gọi AI vá lỗi (chạy 2 passes).
5. **TTS Generation:** Dùng Gradio API. **Điểm đặc biệt:** Tính năng *Just-in-time Pause* - Nếu kết nối Gradio lỗi ngắt giữa chừng, luồng sẽ đóng băng bằng `QWaitCondition`, chờ người dùng nhập link mới rồi resume chạy tiếp.
6. **CapCut Injector:** Cập nhật file nháp của CapCut.

### 2.2. Trí Não Tương Tác AI (`src/gemini_bot.py`)
Đóng gói 100% logic điều khiển web sử dụng thư viện **Playwright**.
- **Quản lý Profile:** Sử dụng `chromium.launch_persistent_context` nạp sẵn Cookie để không bắt người dùng đăng nhập nhiều lần.
- **Hệ thống cảnh báo Hạ cấp (Downgrade Detection):** Trước khi nạp prompt, Bot đọc nội dung HTML (`.model-picker-button`, `.model-title`). Nếu phát hiện account bị ép dùng bản "Flash-Lite", Bot dừng lại báo lỗi để luồng chuyển sang Profile khác, bảo toàn chất lượng câu dịch (Pro/Advanced).
- **Trích xuất dữ liệu:** Quét thẻ `.model-response-text` để bóc tách kết quả từ AI, sau đó truyền về hệ thống xử lý.

### 2.3. Chuyên Gia Xử Lý Phụ Đề (`src/srt_manager.py`)
Là module lớn nhất dự án, xử lý thuật toán tách/gộp chữ và thời gian.
- **`split_srt_file` / `merge_numbered_srt_files`:** Tách file lớn tránh tràn Token AI, và gộp lại bảo toàn Timecode.
- **Hệ thống Auto QA (`analyze_srt_to_file`):** 
  - Tính toán số ký tự trên giây (CPS - Characters Per Second).
  - Soi lỗi *Overlap* (thời gian kết thúc câu trước đè lên thời gian bắt đầu câu sau).
- **Vá lỗi tự động (`replace_blocks_in_folder`):** Đọc bản vá (Patch) từ Gemini và gỡ chính xác từng block (theo Index/Timecode) trong file gốc để thay bằng bản đã sửa, không phá hỏng cấu trúc file SRT.

### 2.4. Công Cơ Nhúng CapCut PC (`src/backend.py`)
Class `CapCutBackend` là module thao tác cấu trúc hạ tầng JSON của CapCut.
- **Tiền xử lý (Sanitize):** Loại bỏ HTML tag, dấu ngoặc kép, tối ưu lại câu chữ.
- **Quản lý Tiến trình:** Sử dụng `psutil` để tìm và kill tiến trình `capcut.exe` trước khi sửa file draft để tránh lỗi `Permission Denied`.
- **Cơ chế Resume TTS:** Quét thư mục đích, dùng `pydub` đo lường `actual_duration_ms` của từng clip `wav`. Bỏ qua các file âm thanh đã sinh thành công, chỉ gọi Gradio tạo bù các file <100ms (file lỗi vỏ).
- **Thuật toán Bypass CapCut Engine:** 
  - Đổi mốc giây sang Microseconds (`1s = 1,000,000µs`).
  - Sinh chuỗi Hash MD5 (`hashlib.md5`) cho media.
  - Sinh mã định danh UUID v4 (`uuid.uuid4()`) bắt buộc.
  - Sắp xếp Timeline thông minh, né đè tiếng (Overlapping) khi tiêm vào mảng `materials.audios` của `draft_content.json`.
